# Binance 1m 永续合约动量监控与四大最高胜率冲高做空系统

监控 Binance **u 本位永续合约（USDM Futures）** 24h 涨幅榜的 1 分钟量价与 MACD，以**24h 涨幅榜 $X$ 分钟内涨幅达 $24\text{h} / N$ 作为基底脉冲（Base Impulse）**，分层叠加 **MACD 动能/背离因子**与**均线阻击/极度偏离因子**，演化出覆盖动量币种从极致脉冲、新高衰竭、初次回撤诱多到二次深跌破位完整生命周期的**四大互斥最高胜率做空信号体系（冲高做空信号组）**。

系统在每次 1m 收盘时间点**单次获取行情快照**，对候选标的并行执行四大信号流水线判定，结合**限价挂单冲高接针 (N=100)** 与**自适应两段式动态止盈止损**，在实盘监控与模拟交易引擎中全自动运转。**每个策略的参数组均完全隔离独立**，保持高内聚、可调优与零干扰。

## 二、系统核心运行机制

### 1. 单次获取行情，统一判定四大信号
- **零冗余 API 开销**：每分钟对齐 1m 收盘时间点，后台仅执行单次 `fetch24hTickers()`。
- **本地 WS K 线推进**：各标的 1m K 线直接由 WebSocket 实时成交流驱动维持在内存 `candleCache` 中，无需反复发起 REST 请求。
- **同频时间切片**：对每个候选币种，传入同一份 K 线数组与行情数据，在 `checkCandles` 中依次流水线判定，确保各信号判定依据的价格与均线指标完全同步。

### 2. 参数组严格分离设计
- 系统通过统一总控配置接口 `UnifiedLiveConfig` 挂载各信号的专属参数对象：
  - `streakConfig`: 新高顶背离做空参数（`STREAK_LIVE_DEFAULT_CONFIG`）
  - `reboundConfig`: 首次跌10%做空参数（`PEAK_REBOUND_LIVE_DEFAULT_CONFIG`）
  - `deepReboundConfig`: 跌到20%+做空参数（`DEEP_REBOUND_LIVE_DEFAULT_CONFIG`）
  - `hourlySuppressionConfig`: 小时线压制做空参数（`HOURLY_SUPPRESSION_LIVE_DEFAULT_CONFIG`）
  - `extremeDevConfig`: 冲高极度乖离做空参数（`EXTREME_DEV_LIVE_DEFAULT_CONFIG`）
- 模块间彼此解耦，支持独立调参、开启/关闭与参数挖掘，互不产生边际副作用。

### 3. 互斥防重与多策略并行仓位管理 (Portfolio Position Quotas)
- **一币一仓互斥 (`preventConflict: true`)**：由 `UnifiedShortStrategyTracker` 统一管理全币种持仓状态。只要某一币种已有在途限价挂单或活跃持仓，互斥拦截其他信号对该币的重复开仓，保证**一币一仓，零信号冲突**。
- **全局最大持仓限制 (`maxPositions: 5`)**：全局最多同时持有 5 笔活跃持仓，防止极端大盘单边暴拉时保证金敞口过载。
- **单策略持仓配额保护 (`maxPositionsPerStrategy: 1`)**：严格限制每个子策略最多同时持有 1 笔仓位，确保五大核心策略【左侧3W底背离、首次跌10%、新高顶背离、跌到20%+、小时线压制】各至少保有 1 笔持仓额度，杜绝单一策略霸占全部持仓槽位。
- **同频优先级撮合**：在同 1 分钟快照中若多个候选标的或策略同时达标，优先撮合高胜率极速策略（冲高极度乖离 / 新高顶背离优先）。

### 4. 限价接针挂单撮合 (N=100)
- 信号触发后，不直接按市价追空，而是以基准价向上溢价挂单：
  $$\text{做空挂单价} = \text{basePrice} \times \left(1 + \frac{\text{dayChangePercent}}{100} / 100\right)$$
- 利用动量标的高位惯性冲针触碰撮合成交，构建安全容错垫。
- 设定 3 分钟有效期，超时未触碰或行情提前下破预估 TP1 则自动撤单。

### 5. 自适应两段式动态止盈止损与保本机制
- **阶段一（平 50% 仓位）**：
  - 止盈 1 = 显式指定 `tp1Percent` (默认 4.0%) 或 $\text{24h 涨幅} / X$
  - 止损 1 = 显式指定 `stopLossPercent` (默认 10.0%) 或 $\text{24h 涨幅} / X$
- **阶段二（平剩余 50% 仓位）**：
  - 止盈 2 = 显式指定 `tp2Percent` (默认 8.0%) 或 $\text{24h 涨幅} \times M / X$
  - **动态保本（Breakeven）**：阶段一止盈达成后，剩余 50% 仓位的止损自动上移至开仓保本价（预留 0.2% 覆盖手续费），锁定无风险交易！
  - 止损 2 = 初始止损位（若未触发保本）或保本价
- 到达最长持仓时限若仍未全部结清，以市价超时平仓。
- **自适应价格精度显示 (`formatPrice`)**：解决低价山寨币（如 PEPE / SHIB / 1000SATS 等价格 $< 0.001$）在 4 位小数下的精度截断与重叠问题，支持 2 到 8 位自适应小数精度。
- **毫秒级平仓冲突去重 (`skipNotify`)**：针对急速大跌穿透 TP1 与 TP2、或急速冲高穿透 SL 的极限行情，优化两段式平仓调度与通知防抖，杜绝重复播报。
- **复合平仓原因映射**：准确记录与展示阶段一和阶段二的综合离场原因（如“阶段一止盈 + 阶段二保本锁定”、“两段全部止盈 🎯”、“保本止损 🛡️”等）。

### 6. 黄金双速模拟交易引擎 (Dual-Speed Ensemble)
基于全市场 119,655 根 1m 真实 K 线的深度量化研究，模拟实盘交易已默认升级为最优**双速做空混合引擎**：
- **双速杠杆配置**：默认 **新高顶背离 10x 独立闪击杠杆 + 顺势衰竭 3x 黄金低杠杆**，在持仓与撮合全流程中动态绑定策略专属杠杆，强平线远在反向暴拉 +33% 之外，彻底杜绝爆仓风险。
- **动态 20% 资产量保证金 (Dynamic Equity Margin)**：单笔保证金不再写死为固定数字，而是动态基于当前账户净权益（Equity）的 **20% 浮动**（`marginRate = 0.20`），并设置 **5 USDT 最低保护线**。5 笔持仓 $\times$ 20% = 100% 满仓风控上限，本金盈利时自动复利增仓，回撤时自动收缩单笔风险敞口。
- **策略参数与环境解耦**：策略与交易参数完全脱离环境变量，纯由内置最优默认值启动，并通过 HTTP REST API 及 Web 控制台实时动态配置与持久化至 `data/paper-trading.json` 的 `configOverrides`。
- **顺势衰竭长波段（首次跌10% / 跌到20%+ / 冲高极度乖离）**：采用 **10.0% 大止损 + 90 分钟长持仓 + TP1=4%(保本) / TP2=8%**，充分吸收 1m 级微观毛刺洗盘，顺势捕获深跌均值回归（实测胜率 80.3%，盈亏比 2.42，最大回撤仅 4.7% ~ 7.0%）。
- **极速假突破闪击战（新高顶背离）**：创 24h 新高标的保留 **15 分钟快速了结**，严防新高单边逼空恶性单。
- **综合表现**：全市场 168h 周期实测 77 笔交易，**胜率 77.9%，盈亏比 2.31，累计总收益 +305.6%，最大回撤仅 6.9%，收益/回撤比 (Calmar) 达 44.21**。
- **HTTP REST API 动态控制**：
  - `GET /api/paper-trading/config`：读取当前交易与四大策略参数。
  - `POST /api/paper-trading/config`：热更新杠杆倍数、保证金比例、最大持仓数与单策略配额等，立即持久化并热加载。
  - `POST /api/paper-trading/reset`：一键重置账户资金与清空在途持仓。
  - `GET /api/paper-trading`：获取详细账户资产、活跃持仓、挂单接针及历史订单。
  - `GET /api/status`：系统主接口在降级或异常时始终注入最新 `paperTrading` 摘要；前端控制台具备 3 秒自主轮询与状态自同步。

### 1. 统一特征向量结构 (`FeatureVector`)
系统将 1m 高频量价与指标解构为 5 大标准化维度：
- **维度 A（区间涨跌幅与实体结构）**：
  - 多周期振幅：`surge[W]`（$W \in [3, 5, 10, 15, 30, 60]$ 分钟冲高）、`drop[W]`（区间回撤）、`closeChange[W]`。
  - K 线形态：`body`（实体%）、`upperWick`（上影线%）、`lowerWick`（下影线%）。
- **维度 B（24h 宏观与榜单上下文）**：
  - 榜单状态：`dayChange`（24h 涨跌幅）、`rank`（全市场涨幅榜实时排名）。
  - 宏观位置：`posIn24hRange`（价格在 24h 最高/最低区间的百分比位置 $0\sim 1$）、`dropFrom24hHigh`（距 24h 滚动峰值回撤%）。
  - 归一化冲高比率：$surgeRatio[W] = surge[W] / |dayChange|$（区间振幅占 24h 涨幅的比例）。
- **维度 C（均线排列与演化动态）**：
  - 5 大周期均线：`MA 5 / 10 / 20 / 30 / 60`（SMA + EMA、斜率 `slope3`、偏离率 `biasPct` 与偏离比率 `biasRatio`）。
  - 触碰与支撑阻力：`support`（下探获支撑）、`resist`（冲高遇阻）、`breakout`（向上突破）、`breakdown`（向下破位）。
  - 排列演化模式（比对近 3 根 1m K 线）：
    - `fresh_bull`（刚成多头起爆拐点）/ `sustained_bull`（持续稳固发散多头）；
    - `fresh_bear`（刚成空头破位拐点）/ `sustained_bear`（持续弱势空头）；
    - `maStreak`（保持当前排列连续根数）、`aboveCount`（价格站上的均线数）。
- **维度 D（MACD 动能与多重背离）**：
  - 动能指标：`dif`、`dea`、`hist`、`histSlope`（柱体斜率）、`difPct`、`deaPct`。
  - 绿柱占比：`greenRatio[N]`（最近 10/15/20/30 根 K 线的绿柱比例）、`greenStreak` / `redStreak`（连绿/连红根数）。
  - 交叉事件时序：`goldenCrossAgo`（金叉距今根数）、`deathCrossAgo`（死叉距今根数）。
  - 背离判定：`topDivergence`（价格新高但 DEA 或柱体未创新高的顶背离）、`bottomDivergence`（底背离）。
- **维度 TF（多周期聚合）**：
  - 由 1m 自动聚合生成的 5m / 15m 多周期状态（`tf5m.stack`、`tf5m.macdHist`、`tf15m.stack` 等）。

### 2. 阶段 0：前兆特征分布统计与客观规律挖掘
在执行网格回测前，系统首先对全量样本回溯统计“大幅冲高段前”与“冲高见顶回撤前”的前驱客观规律：
- **空头策略前置因果**：以【前一段大振幅冲高完成】（$surgeRatio \ge 1/\text{divisor}$）作为前驱，后续在柱体衰竭（实测 $73.8\%$ 样本出现 $histSlope < 0$）或均线受阻/破位时阻击做空；
- **多头策略前置因果**：以【启动前低波收敛蓄势】作为前驱，在均线支撑稳固与 MACD 健康扩张点起爆入场，严防过度追高。

## 四、Telegram 实时推送

系统支持 Telegram 自动化播报，全流程通知均经由代理通道安全出站：

1. **模拟实盘交易通知**：
   - 挂单提交、市价开仓/接针成交、阶段一达成（止盈/减仓/保本）、整单最终结清。

2. **涨幅榜动量异动告警**：
   - 仅监控 24h 涨幅榜，当满足条件的币种数 $\ge \text{TG\_ALERT\_MIN}$ 时播报。
   - 严格防骚扰：币种列表未变化时绝不重复推送；榜单归零自动重置。
3. **接口异常告警（HTTP 418 / 451）**：
   - 当遭遇 Binance IP 封禁或地区受限时，自动告警并记录解封状态。
