# 24h 涨幅榜双信号做空策略研究

本目录包含 Binance 永续合约 24h 涨幅榜**双信号做空策略**的研究代码、回测引擎与历史归档工具。
策略围绕两个独立的互补做空逻辑展开，结合自适应行情两段式动态退出机制，并在实盘监控与模拟交易中协同运行：**双策略同时并行判断，任一满足即开仓**。

## 1. 策略一：空弱反弹 (Weak Rebound Short)

### 策略逻辑与作用
捕捉 24h 涨幅榜首（Rank 1）最强势标的见顶后的第一波深度回撤与超跌反弹。当多头能量衰竭、大级别均线转入空头排列时，反弹冲高遭遇 MA5 阻击收回，属于确定性极高的右侧做空机会。

### 规则与终极参数设定

| 参数模块 | 终极配置设定 | 逻辑与作用 |
| :--- | :--- | :--- |
| **监控标的池** | 曾达 24h 涨幅榜首（Rank 1，持续追踪 48h） | 筛选全市场动量最强、流动性充裕的主升浪龙头 |
| **回撤与反弹** | 最高点回撤 $X = 10\%$，阶段低点反弹 $y = 4\%$ | 保证足够的回撤深度（打破单边多头）与充分的二次诱多反弹 |
| **三均线组合** | MA 5（短周期阻击）/ MA 15（中周期过渡）/ MA 30（长周期天花板） | 经典趋势均线系统 |
| **均线空头排列** | 严格呈空头排列（$\text{MA}_{30} > \text{MA}_{15} > \text{MA}_5$） | 确认空头趋势占据绝对主导 |
| **长均线压制** | 长均线高于反弹高点 $\ge 0.5\%$（$\text{MA}_{30} \ge \text{High} \times 1.005$） | 确保反弹处于长周期均线安全天花板下方，远离突破风险 |
| **短均线阻击** | $\text{High} > \text{MA}_5$ 且 $\text{Close} < \text{MA}_5$ | 上影线试探冲高受阻，收盘跌破短均线确立衰竭 |
| **动能过滤** | 近 20 根 1m MACD 绿柱占比 $> 65\%$ | 保证反弹阶段有多头柱体释放，而非死寂无波动的阴跌 |
| **均线倾斜确认** | 开启中长均线（MA30 与 MA15）向下倾斜确认 | 杜绝均线走平或拐头向上的假空头排列，顺应均线重力下行 |
| **动态退出参数** | $x = 35, n = 2.0, m = 3.0$，最大持仓 45 分钟 | 第一段分母 $x=35$ 快速锁定高胜率，第二段止损 $2.0\times$、止盈放大至 $3.0\times$（持仓放宽至 45m，盈亏比翻倍至 1.32，净收益创最佳） |

### 研究与回测命令
```bash
# 运行榜一峰值反弹两段式做空参数挖掘
npm run mine:peak-rebound -- --data data/hourly \
  --minutes-data data/research/peak-rebound-1m \
  --out reports/research/peak-rebound
```

## 2. 策略二：空连阳 (Streak Short)

### 策略逻辑与作用
专注捕捉历史 24h 涨幅榜 Top 10 极端情绪高潮时的多头透支衰竭。连续收阳且伴随高换手振幅，MACD 绿柱极度饱和但无法突破超短均线压制，且带有试探见顶上影线，属于极高盈亏比的左侧精准阻击。

### 规则与终极参数设定

| 参数模块 | 终极配置设定 | 逻辑与作用 |
| :--- | :--- | :--- |
| **榜单与形态** | 历史涨幅榜 Top 10，连续 $\ge 2$ 根 1m 阳线 | 聚焦全市场最亢奋的多头集中地 |
| **上影线形态** | $0.5\% \le \text{上影线比率} < 30\%$ | 必须有试探见顶回落，拒绝光头大阳线陷阱 |
| **30 分钟振幅** | $30\text{m 振幅} \ge 24\text{h 涨幅} / 12$ | 保证过去半小时换手充分、剧烈博弈，非假突破 |
| **均线压制** | MA [3, 7, 15] 均无支撑 | 消除超短均线反弹托底隐患 |
| **MACD 动能** | 近 30 根绿柱占比 $> 70\%$，且末尾连续 $\ge 7$ 根全绿 | 动能已在极端高位极度饱和，随时面临多翻空 |
| **动态止盈止损** | $X = 50, N = 1.5, M = 3.0$（最长持仓 15m） | 比原 $X=60$ 给足适度波动空间，避免被微小毛刺误扫 |

### 研究与回测命令
```bash
# 1. 补全市场小时数据
npm run research -- fetch --days 30 --data data/hourly

# 2. 为历史入榜币种下载分钟归档数据并运行回测
npm run research:wick -- --data data/hourly \
  --minutes-data data/research/wick-1m --minute-source archive \
  --out reports/research/wick-study

# 3. 离线复现回测
npm run research:wick -- --data data/hourly \
  --minutes-data data/research/wick-1m --offline \
  --out reports/research/wick-replay
```

## 3. 双策略协同运行与模拟交易 (Paper Trading)

系统在生产环境及模拟盘交易引擎（`src/paper-trading.ts`）中实现了双策略的无缝协同：
- **同时并行判断**：监控引擎在每次 1m K 线收盘后，对标的并行检测【空弱反弹】与【空连阳】条件，**任一策略满足均立即开仓**。
- **差异化退出参数**：
  - 空弱反弹触发：自动应用 $x = 35, n = 2.0, m = 3.0$，超时时限 45 分钟。
  - 空连阳触发：自动应用 $X = 50, N = 1.5, M = 3.0$，超时时限 15 分钟。
- **冲突防重保护**：由 `UnifiedShortStrategyTracker` 统一管理持仓状态。当某一币种已有在途挂单或活跃持仓时，互斥拦截另一策略的重复入场，保证每币同时最多持有一笔仓位。
- **全链路标签可视化**：订单从提交、限价接针、阶段一止盈/止损、阶段二全部结清，均全程标注 `【空连阳】` 或 `【空弱反弹】`，并在前端面板与 Telegram 通知中实时展示。
