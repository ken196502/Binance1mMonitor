# 24h 涨幅榜双信号做空策略研究

本目录包含 Binance 永续合约 24h 涨幅榜**双信号做空策略**的研究代码、回测引擎与历史归档工具。
策略围绕两个独立的互补做空逻辑展开，结合自适应行情两段式动态退出机制，并在实盘监控与模拟交易中协同运行。

---

## 1. 信号一：空连阳研究 (Streak Short)

### 原理说明
信号收盘确认后**直接市价开空**；同一笔仓位第一段按极小止盈/极小止损**平初始仓位50%**，第二段按大止盈/小止损**平剩余仓位100%**。两段合并统计整笔交易的胜率与盈亏比。

### 运行方式
```bash
# 1. 补全市场小时数据
npm run research -- fetch --days 30 --data data/hourly

# 2. 为历史入榜币种下载分钟归档数据并运行回测
npm run research:wick -- --data data/hourly \
  --minutes-data data/research/wick-1m --minute-source archive \
  --out reports/research/wick-study

# 3. 离线复现回测
npm run research:wick -- --data data/hourly \
  --minutes-data data/research/wick-1m --offline \
  --out reports/research/wick-replay
```

### 退出与自适应参数
- 第一阶段：止盈 = `24h涨幅 / x`，止损 = `24h涨幅 / x`（平仓50%）
- 第二阶段：止损 = `24h涨幅 × n / x`，止盈 = `24h涨幅 × m / x`（平剩余全部）
- 默认网格基准：$x=60, n=1.5, m=4.0$。所有幅度均相对原始入场价。

## 2. 信号二：空弱反弹研究 (Peak Rebound Short)

### 原理说明
跟踪 24h 涨幅榜首（Rank 1），当币种创出阶段新高后出现急跌回撤（$\ge 10\%$），随后在均线空头排列压制下出现弱反弹（$\ge 4\%$ 且斐波那契回撤 $\le 50\%$），在短均线 MA5 阻击点且信号线遇阻（阴线或显著上影线）时开空。

### 运行方式
```bash
# 运行榜一峰值反弹两段式做空参数挖掘
npm run mine:peak-rebound -- --data data/hourly \
  --minutes-data data/research/peak-rebound-1m \
  --out reports/research/peak-rebound
```

## 3. 同步到模拟交易 (Paper Trading)

双信号策略已全面同步至系统核心模拟交易模块（`src/paper-trading.ts`）：
- **信号标记**：模拟交易在开仓及挂单时，均携带明确信号标签：`【空连阳】` 或 `【空弱反弹】`。
- **差异化退出参数**：不同信号依据自身研究的最优参数自适应分配 $x, n, m$ 与超时时限。
- **冲突防重**：相同标的由 `UnifiedShortStrategyTracker` 进行统一仓位调度，避免双信号同币竞争冲突。
- **全链路感知**：网页前端看板（活跃持仓卡片、限价挂单列表、历史平仓表格）与 Telegram 播报消息均实时展示信号分类标签。

## 4. 目录核心文件索引

- `src/unified-short-strategy.ts`：生产双信号做空统一调度引擎

- `research/wick*.ts`：空连阳策略的历史数据处理与回测引擎
- `research/peak-rebound*.ts`：空弱反弹策略的历史回测与动态退出挖掘
- `research/cli.ts`：研究命令行交互入口
- `research/data.ts` & `gainers-data.ts`：全市场小时池与入榜币种分钟归档下载器
